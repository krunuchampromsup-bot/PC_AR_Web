CPU

สมองหลักในการประมวลผลคำสั่ง

Central Processing Unit
• หน่วยประมวลผลกลาง
• วัดความเร็วเป็น GHz
• ยิ่ง Core เยอะ ยิ่งทำงานไว

RAM

หน่วยความจำชั่วคราวความเร็วสูง

Memory (RAM)
• พักข้อมูลให้ CPU
• ช่วยให้เปิดแอปได้พร้อมกัน
• ข้อมูลหายเมื่อปิดเครื่อง
🧊 ดูโมเดล AR 3D
SSD

พื้นที่เก็บข้อมูลความเร็วสูงพิเศษ

Solid State Drive
• เก็บข้อมูลถาวร
• บูตเครื่องไวกว่า HDD
• ไม่มีชิ้นส่วนขยับ ทนทาน
🧊 ดูโมเดล AR 3D
MAINBOARD

แผงวงจรหลักที่เชื่อมต่อทุกอย่าง

Motherboard
• ศูนย์กลางการเชื่อมต่อ
• มีช่องเสียบ CPU/RAM/VGA
• ควบคุมการรับส่งข้อมูล
🧊 ดูโมเดล AR 3D
PSU

แหล่งจ่ายไฟให้กับคอมพิวเตอร์

Power Supply Unit
• แปลงไฟบ้านเป็นไฟคอม
• วัดพลังงานเป็น Watt (W)
• หัวใจสำคัญของความเสถียร

• ช่วยเรื่องการระบายอากาศ
